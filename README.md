✦ About

Minesweeper is a simple Android app that displays a standalone HTML Minesweeper game using WebView.

Built with a straightforward philosophy: keep it lightweight, keep it clean, and keep it simple.

The Android app serves as a container for the game, avoiding the overhead of a full native implementation.

⚡ Highlights

- 🪶 Lightweight — minimal overhead.
- 🎯 Simple — focused entirely on the game.
- 🎨 Clean — a modern, distraction-free experience.
- 📱 Android APK — install and play.
- 🌐 HTML-based — powered by HTML, CSS, and JavaScript.
- 🔌 Local-first — designed to run the game locally without requiring a remote website.

🛠️ How It Works

Android App
    └── WebView
          └── Minesweeper
                ├── HTML
                ├── CSS
                └── JavaScript

The game runs inside Android WebView. The native layer provides the app container, while the HTML project handles the game interface and logic.
